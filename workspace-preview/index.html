Two model explanations

This service compares both fixed families. It does not select a winning or true model.

Response model and fit scope

Zero-drift, nonrelativistic electrons; full tangential acceptance; normal kinetic-energy filtering. No sheath, drift, background or real-instrument calibration is modelled.

If omitted, the service retains an honest unsupported result. No calibration is assumed.

Comma-separated thermal energies kBT/e, not temperatures in kelvin. Both models use this shared grid. A grid optimum is not a continuous or global optimum.

Reduced χ² is descriptive for this constrained grid fit, not a calibrated p-value.

Noise and feasible measurements

Independent Gaussian noise. Each prediction band is ±zσ; the required difference for disjoint bands is 2zσ. Touching bands do not separate.

Noise SD, detectable difference and hard allowance are different quantities. This version has no independent instrument detection-floor or hard-allowance input; it evaluates the declared prediction bands only.

The simulation holds fitted predictions fixed. It does not refit the models, propagate fitted-parameter uncertainty or estimate a probability that a model is true.

Supplied feasible settings

Angles and normal-energy limits you permit for comparison. Suggestions are conditional on this finite grid and do not approve an experiment.
